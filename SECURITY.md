# Security policy

Report suspected vulnerabilities in the STREAM Connect Agent to
**security@moyaflow.de**. Do not open a public issue.

Reports are handled under the MOYAFLOW vulnerability disclosure policy:

- English: <https://www.moyaflow.de/en/legal/security/>
- German: <https://www.moyaflow.de/de/legal/sicherheit/>
- Machine-readable: <https://www.moyaflow.de/.well-known/security.txt>

Please include the agent version (`stream-connect-agent version`), the
operating system, and steps to reproduce.

Security fixes are released as new versions; published releases are never
changed. Every release is signed and carries build provenance; see
[README.md](README.md#verify-a-download).
